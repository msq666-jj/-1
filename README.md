# 钢铁禁区 · 坦克大战

一个无需构建、直接打开即可游玩的 HTML5 Canvas 坦克大战。包含三波敌军、可破坏砖墙、钢制掩体、敌方 AI、随机补给、触屏控制和音效。

## 开始游戏

直接用浏览器打开 `index.html`，或用任意静态服务器托管该目录。

```powershell
npx serve .
```

## 操作

- `WASD` 或方向键：移动
- 鼠标：瞄准
- 空格或鼠标左键：发射
- `P` / `Esc`：暂停或继续
- `R`：结束后重新开始

触屏设备会自动显示方向键和射击按钮。

## 技术

- 原生 HTML、CSS、JavaScript
- HTML5 Canvas 2D 渲染
- Web Audio API 音效
- 无外部依赖
